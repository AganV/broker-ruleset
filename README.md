# Broker Ruleset

个人收集、整理与维护的 Surge 券商分流规则集。目前仅包含富途牛牛（Futubull / FTNN）。

**Surge**

```ini
RULE-SET,https://raw.githubusercontent.com/AganV/broker-ruleset/main/Futubull.list,[Replace with your policy]
```
